# 🌧️ Rainbox

**A little escape from the noise.**

Rainbox is a personal web project built around the atmosphere of rainy places, cozy environments, and ambient sounds.

Explore rainy locations, enter your own little rain room, and enjoy the atmosphere.

## ✨ Features

- 🌍 **Random Rainy Places** — Discover rainy locations around the world.
- 🌧️ **Rain Room** — Immerse yourself in a cozy rainy atmosphere.
- 🌃 **Night City** — Experience the atmosphere of rainy city nights.
- 🎵 **Music Player** — Listen to ambient tracks with playback controls, volume adjustment, and automatic track switching.
- 🌦️ **Weather Integration** — Uses Open-Meteo to discover suitable rainy locations.
- 🎨 **Minimalist UI** — Dark interface, liquid glass elements, and subtle animations.

## 🛠️ Tech Stack

- Vue 3
- TypeScript
- Vite
- Tailwind CSS v4
- Open-Meteo API

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Vanoermak62/Rainbox.git
```

Navigate to the project directory:

```bash
cd Rainbox
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 🎧 About Music & Copyright

The music player is part of the project, but audio files and the associated track catalog are intentionally excluded from this repository.

Why? Copyright and licensing considerations. I don't own the rights to redistribute all the tracks used during development, so I'd rather keep them out of the public repository than risk copyright infringement.

The player can be populated with properly licensed or original music in the future.
